# FLangInterpreter
> by LaPolicia

# How to launch
You can use convenient `run.sh` script:
```shell
./run.sh  # prompt mode
./run.sh sc-examples/1.txt
```

# Code Formatting
***PLEASE*** use Spotless before commiting
```shell
./gradlew spotlessCheck  # show inconsistencies
./gradlew spotlessApply  # fix them
```
